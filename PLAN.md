# Learn AI — Course Redesign Plan

## Core Philosophy
- **Speed over depth** — Learn prompting in 10 minutes, not 10 hours
- **Copy-paste value** — Every lesson has prompts they can use immediately
- **Show, don't tell** — Before/after examples, not theory
- **Respect their time** — 2-3 min per lesson, no fluff
- **Dopamine hits** — Each lesson delivers ONE clear win

## Target Audience
- Never used AI, or used it but got meh results
- Non-technical (no CLI, no code)
- Wants practical skills, not understanding of transformers
- Short attention span, will bounce if bored

## Course Structure

### Landing Page (index.html)
- Hero: "Learn AI Prompting in 10 Minutes"
- Visual progress path (not boring list)
- "Start Learning" CTA above fold
- Social proof: "Join X learners" (future)

## Design Principles

### Each Lesson Must Have:
1. **Hook** — Why should I care? (1 sentence)
2. **Concept** — The one thing to learn (2-3 paragraphs max)
3. **Example** — Before/after or copy-paste prompt
4. **Try It** — Specific prompt to copy and test
5. **Summary** — One sentence takeaway

### Visual Design:
- Dark theme (consistent with webprompts.org)
- Progress indicator (Lesson X of 12)
- Copy buttons on all prompts
- Mobile-first (many read on phone)
- Generous whitespace
- No walls of text

### Navigation:
- Previous / Next lesson buttons
- "Back to Course" link
- Progress saved (future: localStorage)
